# Танки на минималках 2 🎮

Простая игра "Танки" на Python с использованием библиотеки tkinter.

## Управление 🎮

| Клавиша | Действие |
|---------|----------|
| **W** | Движение вверх |
| **S** | Движение вниз |
| **A** | Движение влево |
| **D** | Движение вправо |
| **ПРОБЕЛ** | Стрельба |

## Игровая механика 🎯

### Игрок 🔴
- Красный танк
- Начальное здоровье: 100 HP
- Начальные боеприпасы: 100
- Начальное топливо: 10000
- Скорость: 2

### Враги 🔵
- Синие танки (7 штук)
- ИИ преследует игрока
- Стреляют при наведении
- Скорость: 2

### Бонусы ⭐

| Бонус | Эффект |
|-------|--------|
| ❤️ **Сердце** | Восстанавливает 20 HP (максимум 100) |
| 💣 **MISSLE** | +10 боеприпасов, +100 топлива |
| ⚡ **Молния** | Ускорение x3 на 5 секунд |

### Столкновения 💥
- **Кирпич (BRICK)** - разрушается от выстрела
- **Бетон (CONCRETE)** - не разрушается
- **Вода (WATER)** - замедляет движение
- **Стены по краям** - непреодолимые

## Установка и запуск 🚀

### Требования:
- Python 3.8 или выше
- Установленный tkinter (входит в стандартную установку Python)

### Запуск:
```bash
python main.py
Возможные проблемы и решения 🔧
Чёрные квадраты вместо текстур
Убедитесь, что папка img находится в той же директории, что и main.py

Проверьте, что все файлы изображений на месте

Имена файлов должны точно соответствовать указанным в load_textures()

Танк не двигается
Проверьте, что включена английская раскладка клавиатуры

Убедитесь, что есть топливо (отображается в правом верхнем углу)

Враги не стреляют
Враги стреляют только когда смотрят на игрока

У них должны быть боеприпасы

Проверьте консоль на сообщения о выстрелах

Отображение статистики 📊
В правом верхнем углу отображается:

HP - здоровье

Ammo - боеприпасы

Fuel - топливо

Speed - текущая скорость

Примечания 📝
Игра автоматически запускается без стартового меню

При смерти игрока появляется надпись "GAME OVER"

Для перезапуска нужно закрыть и открыть игру заново
